# Quickstart

Get real-time technical analysis data from Cerebrus Pulse in under 5 minutes.

## Try the Free Demo First

No wallet needed — the `/demo/{coin}` endpoint returns the full 1h + 4h analysis for **BTC and ETH**, free (3 requests/min):

```bash
curl https://api.cerebruspulse.xyz/demo/BTC
```

Ready for every supported coin, all 6 timeframes and higher rate limits? Set up x402 payments below.

## Prerequisites

- A wallet with USDC on **Base** (chain ID 8453) or **Solana** (mainnet)
- Python 3.10+ or Node.js 18+

## 2. Make Your First Request

<Tabs>
  <TabItem label="Python">
    ```python
    import asyncio
    import os
    from eth_account import Account
    from x402 import x402Client
    from x402.http.clients import x402HttpxClient
    from x402.mechanisms.evm.exact import register_exact_evm_client

    # A dedicated, low-balance Base wallet (keep the key out of source code)
    PRIVATE_KEY = os.environ["BASE_WALLET_PRIVATE_KEY"]

    async def main():
        x402 = x402Client()
        register_exact_evm_client(x402, Account.from_key(PRIVATE_KEY))
        x402.set_spend_controls({"max_amount_per_payment": "$0.10"})

        async with x402HttpxClient(x402) as client:
            # Fetch BTC technical analysis (1h + 4h timeframes)
            resp = await client.get(
                "https://api.cerebruspulse.xyz/pulse/BTC",
                params={"timeframes": "1h,4h"}
            )
            data = resp.json()

            print(f"BTC Price: ${data['price']['current']:,.2f}")
            print(f"Confluence: {data['confluence']['score']} ({data['confluence']['bias']})")

            for tf, analysis in data["timeframes"].items():
                ind = analysis["indicators"]
                print(f"\n[{tf}] RSI: {ind['rsi_14']} ({ind['rsi_zone']})")
                print(f"[{tf}] Trend: {ind['trend']['label']}")

    asyncio.run(main())
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```typescript
    import { wrapFetchWithPaymentFromConfig } from "@x402/fetch";
    import { ExactEvmScheme } from "@x402/evm";
    import { privateKeyToAccount } from "viem/accounts";

    // A dedicated, low-balance Base wallet (keep the key out of source code)
    const account = privateKeyToAccount(process.env.BASE_WALLET_PRIVATE_KEY as `0x${string}`);

    const fetchWithPayment = wrapFetchWithPaymentFromConfig(fetch, {
      schemes: [{ network: "eip155:8453", client: new ExactEvmScheme(account) }],
      spendControls: { maxAmountPerPayment: "$0.10" },
    });

    const response = await fetchWithPayment(
      "https://api.cerebruspulse.xyz/pulse/BTC?timeframes=1h,4h"
    );

    const data = await response.json();

    console.log(`BTC Price: $${data.price.current.toLocaleString()}`);
    console.log(`Confluence: ${data.confluence.score} (${data.confluence.bias})`);
    ```
  </TabItem>
  <TabItem label="cURL">
    ```bash
    # Step 1: an unpaid request returns 402 with the x402 v2 terms
    curl -i "https://api.cerebruspulse.xyz/pulse/BTC?timeframes=1h,4h"
    # HTTP/1.1 402 Payment Required
    # payment-required: <base64 x402 v2 terms: price, networks, payTo>

    # Step 2: an x402 v2 client signs a USDC payment and retries the same
    # request with a PAYMENT-SIGNATURE header. The receipt comes back in
    # PAYMENT-RESPONSE. See the Python and TypeScript tabs.
    ```
  </TabItem>
</Tabs>
