## Notes

- **Case-insensitive**: `btc`, `BTC`, and `Btc` all work.
- **1000-token markets**: Hyperliquid lists PEPE only as `kPEPE`, a market in units of 1000 PEPE. Use `PEPE` or `kPEPE`; responses give prices per 1000 PEPE and say so in `market_symbol` and `price_unit`.
- **The list is curated**: coins are added to the API's allowlist by hand, not automatically when Hyperliquid lists a market.

## Programmatic Discovery

# Free — no payment required
curl https://api.cerebruspulse.xyz/coins

```json

```

Always use `GET /coins` for programmatic workflows rather than hardcoding this list.
