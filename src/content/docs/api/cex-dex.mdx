# GET /cex-dex/\{token\}

<PriceBadge endpoint="cex-dex" />

The divergence between Coinbase's price for a token and an on-chain price, from a snapshot the scanner
refreshes every 5 minutes. The on-chain side is Chainlink where a feed exists; `dex_source` says which
source it was.

:::caution[Fallback prices]
When no on-chain price was found, the scanner falls back to another source. A `dex_source` of `coinbase`
means both sides are Coinbase's own price: the divergence then reads 0 and says nothing.
:::

This endpoint can be withdrawn: while Coinbase-derived data is switched off it answers 503 and quotes no price.

## Request

```
GET https://api.cerebruspulse.xyz/cex-dex/{token}
```

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `token` | string | Yes | Token symbol, case-insensitive. Aliases: `WETH` → `ETH`, `WBTC` → `BTC`, `BITCOIN` → `BTC`, `ETHEREUM` → `ETH`. The snapshot on 2026-09-24 covered 15 tokens: AAVE, ARB, AVAX, BTC, CRV, DOGE, ETH, FIL, LINK, NEAR, OP, SEI, SOL, SUI, UNI. Another token gets a 400 listing the available ones, not charged. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `endpoint` | string | `cex-dex` |
| `token` | string | The token, after aliases |
| `timestamp_iso` | string | When the snapshot was taken (ISO 8601) |
| `divergence.cex_price` | number | Coinbase price (USD) |
| `divergence.dex_price` | number | The on-chain price (USD) |
| `divergence.dex_source` | string | Where `dex_price` came from: `chainlink`, or a fallback such as `coinbase` or `defillama` |
| `divergence.spread_bps` | number | The divergence in basis points, as the scanner reports it |
| `divergence.spread_pct` | number | The same in percent |
| `divergence.direction` | string | `cex_premium` or `dex_premium` |
| `divergence.interpretation` | string | The direction in words |
| `meta` | object | Common metadata ([Response Schemas](/reference/response-schemas#meta)); `data_age_seconds` is the snapshot's age, and above 600 seconds `meta.warning` is `stale_data` |
| `meta.offering` | string | `pulse_cex_dex` |
| `meta.refresh_interval_minutes` | number | `5` |
| `meta.cex_source` | string | `coinbase` |

## Errors

| Status | Reason |
|--------|--------|
| 400 | Invalid symbol (before any price is quoted), or a token the snapshot does not cover (not charged) |
| 402 | Payment required (the standard x402 flow) |
| 429 | Rate limit exceeded |
| 503 | Withdrawn, service disabled, payments down, or the CEX-DEX feed is missing or stale; no price is quoted |
| 504 | Engine timeout (not charged) |

The [/screener](/api/screener) carries the same divergence per market in `cex_dex_spread_bps`.
