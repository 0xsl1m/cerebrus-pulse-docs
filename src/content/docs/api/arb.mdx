# GET /arb

<PriceBadge endpoint="arb" />

A market stress index from a cross-chain arbitrage scanner that runs every 5 minutes: how many cross-chain
price dislocations the most recent scans found and how wide they were, summarised as one level and score.
The thresholds are heuristics.

## Request

```
GET https://api.cerebruspulse.xyz/arb
```

### Query Parameters

| Parameter | Type | Default | Range | Description |
|-----------|------|---------|-------|-------------|
| `limit` | integer | `10` | 1–50 | How many of the most recent scans to analyze. Outside the range the request is refused with 400 before any price is quoted. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `endpoint` | string | `arb` |
| `timestamp_iso` | string | When the response was computed (UTC) |
| `stress_index.level` | string | `LOW`, `MODERATE`, `HIGH` or `EXTREME` (see below) |
| `stress_index.score` | number | 0 to 1 within the level's band |
| `stress_index.interpretation` | string | The level in words |
| `statistics.scans_analyzed` | number | Scans read (up to `limit`) |
| `statistics.total_opportunities` | number | Dislocations found across those scans |
| `statistics.total_profitable` | number | Of those, the ones the scanner rated profitable after costs |
| `statistics.avg_spread_bps` | number | Mean spread of the dislocations, in basis points |
| `statistics.max_spread_bps` | number | Widest spread, in basis points |
| `statistics.unique_tokens_involved` | array | Tokens in the dislocated pairs |
| `statistics.chain_routes` | array | Buy-chain to sell-chain routes, as `chain->chain` |
| `recent_scans[].timestamp` | string | When the scan ran |
| `recent_scans[].scan_duration_s` | number | How long it took |
| `recent_scans[].opportunities_found` | number | Dislocations in the scan |
| `recent_scans[].profitable_count` | number | Of those, rated profitable |
| `recent_scans[].chains_scanned` | number | Chains checked |
| `recent_scans[].pairs_scanned` | number | Token pairs checked |
| `recent_scans[].opportunities` | array | Optional. Present when the scan found any: `pair`, `spread_bps` and `estimated_profit_usd` for each |
| `meta` | object | Common metadata ([Response Schemas](/reference/response-schemas#meta)) |
| `meta.offering` | string | `pulse_stress` |
| `meta.scan_interval_minutes` | number | `5` |
| `meta.data_source` | string | The scanner's price sources: DeFiLlama, Chainlink and Coinbase |
| `meta.excluded` | string | Optional. Present while Coinbase-derived data is switched off: opportunities with a Coinbase-priced leg are left out |
| `meta.cached` | boolean | Optional. `true` when the result is reused because no new scan has been logged |

`meta.as_of.arb_log` is the time of the newest scan.

### Stress levels

| Level | When | Score |
|-------|------|-------|
| `LOW` | No dislocations, or at most 2 with every spread under 100 bps | 0 to 0.3 |
| `MODERATE` | At most 5 dislocations, or a widest spread under 200 bps | 0.3 to 0.7 |
| `HIGH` | At most 10 dislocations, or a widest spread under 500 bps | 0.7 to 0.9 |
| `EXTREME` | More, and wider | 0.9 to 1.0 |

## Example

No captured example: the data capture held no arbitrage log. The fields above follow the engine's
`process_arb`.

## Errors

| Status | Reason |
|--------|--------|
| 400 | `limit` outside 1–50 (before any price is quoted), or no scan data yet (not charged) |
| 402 | Payment required (the standard x402 flow) |
| 429 | Rate limit exceeded |
| 503 | Service disabled, payments down, or the arbitrage log is missing or stale; no price is quoted |
| 504 | Engine timeout (not charged) |
