# GET /coins

<Badge text="Free" variant="success" />

Returns the list of all coins currently available for analysis. No payment required. Not rate limited.

## Request

```
GET https://api.cerebruspulse.xyz/coins
```

No parameters.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `coins` | string[] | The available market symbols, sorted |
| `count` | number | How many there are |
| `meta` | object | `provider` and `offering` |

## Notes

- The coin list is dynamic and may change as new perpetuals are added on Hyperliquid.
- Always use this endpoint for discovery rather than hardcoding coin lists.
- Coin tickers are case-insensitive in API requests (`btc`, `BTC`, and `Btc` all work).
- Some tokens trade on Hyperliquid only as 1000-token markets: `PEPE` is the `kPEPE` market, so its prices are per 1000 PEPE and its open interest counts 1000-PEPE units. Responses say so in `market_symbol` and `price_unit`, and `kPEPE` is accepted as a symbol too.
- The same list is also served at `/api/v1/coins`.
