# GET /depeg

<PriceBadge endpoint="depeg" /> <Badge text="Powered by Chainlink" variant="note" />

How far USDC is from $1.00, read from Chainlink's USDC/USD feed on Arbitrum, plus whether the Arbitrum
sequencer was up when the feeds were read.

## Request

```
GET https://api.cerebruspulse.xyz/depeg
```

No parameters.

## Response

| Field | Type | Description |
|-------|------|-------------|
| `endpoint` | string | `depeg` |
| `timestamp_iso` | string | When the response was computed (UTC) |
| `usdc.price_usd` | number | Chainlink USDC/USD price |
| `usdc.deviation_bps` | number | `abs(price_usd − 1) × 10000` |
| `usdc.deviation_pct` | number | The same deviation in percent |
| `usdc.peg_status` | string | `HEALTHY` (< 10 bps), `ELEVATED` (10–50), `WARNING` (50–200) or `CRITICAL` (200 or more) |
| `usdc.risk_level` | string | `low`, `medium`, `high` or `critical`, matching `peg_status` |
| `usdc.interpretation` | string | The deviation in words |
| `infrastructure.arbitrum_sequencer` | string | `up`, `down`, or `unknown` when the check itself failed. While it is not `up`, treat Arbitrum Chainlink prices as possibly stale |
| `infrastructure.chainlink_feeds_active` | number | Chainlink prices in the snapshot |
| `meta` | object | Common metadata ([Response Schemas](/reference/response-schemas#meta)) |
| `meta.offering` | string | `pulse_depeg` |
| `meta.chainlink_data_age_seconds` | number \| null | Age of the Chainlink snapshot. Above 120 seconds, `meta.warning` is `stale_chainlink_data` |
| `meta.chainlink_round_age_seconds` | number \| null | Age of the USDC round, when the snapshot records it; null otherwise |
| `meta.oracle_network` | string | `arbitrum` |
| `meta.feed_address` | string | The Chainlink USDC/USD feed on Arbitrum |

## Errors

| Status | Reason |
|--------|--------|
| 400 | No Chainlink snapshot yet, or no USDC price in it (the error names the sequencer status); not charged |
| 402 | Payment required (the standard x402 flow) |
| 429 | Rate limit exceeded |
| 503 | Service disabled, payments down, or the Chainlink feed is missing or stale; no price is quoted |
| 504 | Engine timeout (not charged) |
