# GET /funding/\{coin\}

<PriceBadge endpoint="funding" />

Funding rate statistics for one Hyperliquid perpetual over a lookback window. Hyperliquid pays funding
**every hour**, and every rate here is an hourly rate: `0.0000125` (0.00125% an hour) is its baseline, which
annualizes to 10.95%.

## Request

```
GET https://api.cerebruspulse.xyz/funding/{coin}
```

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `coin` | string | Yes | Market symbol, case-insensitive (`BTC`, `ETH`, `SOL`). [`GET /coins`](/api/coins) lists them. |

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `lookback_hours` | integer | `24` | Window in hours, 1–168. Outside that range the request is refused with 400 before any price is quoted. |

## Response

The statistics are flat, at the top level. The response carries no list of individual records.

| Field | Type | Description |
|-------|------|-------------|
| `endpoint` | string | `funding` |
| `coin` | string | The symbol, upper-case |
| `records` | number | Hourly funding records in the window (at most 500) |
| `lookback_hours` | number | The window used |
| `avg_funding_rate` | number | Mean hourly funding rate over the window |
| `annualized_pct` | number | `avg_funding_rate × 24 × 365 × 100` |
| `funding_interval_hours` | number | `1`: Hyperliquid pays funding hourly |
| `current` | number | The newest record's hourly rate |
| `min` | number | Lowest hourly rate in the window |
| `max` | number | Highest hourly rate in the window |
| `positive_pct` | number | Share of records with a positive rate (longs paid shorts), in percent |
| `meta` | object | Common metadata ([Response Schemas](/reference/response-schemas#meta)) |
| `meta.offering` | string | `pulse_funding` |

`meta.as_of.funding` is the time of the newest funding record in the window.

## Errors

| Status | Reason |
|--------|--------|
| 400 | `lookback_hours` outside 1–168 (before any price is quoted), or no funding records in the window (not charged) |
| 402 | Payment required (the standard x402 flow) |
| 404 | Unknown coin (before any price is quoted) |
| 429 | Rate limit exceeded |
| 503 | Service disabled, payments down, or the funding feed is missing or stale; no price is quoted |
| 504 | Engine timeout (not charged) |
