# GET /screener

<PriceBadge endpoint="screener" />

Scans every covered Hyperliquid perpetual on its 1h candles and returns one compact row per market, sorted by
`signal_strength`: how extreme the readings are, not which way they point. Use it to find the markets worth
a closer look, then call [/pulse](/api/pulse) on them.

The full scan is cached for 60 seconds; each request takes its own `top_n` rows from it.

## Request

```
GET https://api.cerebruspulse.xyz/screener
```

### Query Parameters

| Parameter | Type | Default | Range | Description |
|-----------|------|---------|-------|-------------|
| `top_n` | integer | `50` | 1–50 | How many rows to return. Outside the range the request is refused with 400 before any price is quoted. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `endpoint` | string | `screener` |
| `coins_scanned` | number | Markets the scan computed |
| `top_n` | number | Rows returned |
| `results[].coin` | string | The symbol |
| `results[].market_symbol` | string | Hyperliquid's name for the market (`kPEPE` for PEPE) |
| `results[].price_unit` | string | What `price` is quoted per: `1 BTC`, or `1000 PEPE` |
| `results[].price` | number | Hyperliquid mid price in USD per `price_unit`. Absent when the feed has no mid |
| `results[].signal_strength` | number | 0 to 3.5, higher = more extreme: `abs(RSI − 50) / 50` + `min(abs(z) / 2, 1)` + `min(ATR% / 5, 1)` + 0.5 when the trend has a direction. It measures intensity, not direction |
| `results[].rsi_14` | number \| null | 1h RSI (14) |
| `results[].rsi_zone` | string | `overbought`, `bullish`, `neutral`, `bearish`, `oversold` or `unknown`, as in [/pulse](/api/pulse) |
| `results[].trend` | string | The 1h trend label: `bullish`, `weak_bullish`, `neutral`, `weak_bearish`, `bearish` or `insufficient_data` |
| `results[].zscore` | number \| null | 1h z-score of the close against the last 100 closes |
| `results[].atr_pct` | number \| null | 1h ATR as a percentage of the close |
| `results[].vol_regime` | string | From `atr_pct`: `LOW` (< 1), `NORMAL` (< 3), `HIGH` (< 6), `EXTREME`, or `UNKNOWN` |
| `results[].funding_rate` | number \| null | Current Hyperliquid funding rate, per hour |
| `results[].funding_bias` | string | `long_pays` above the 0.0000125/h baseline, `short_pays` below −0.0000125/h, else `neutral` |
| `results[].confluence_bias` | string | The 1h confluence bias: `bullish`, `bearish`, `neutral` or `unknown` |
| `results[].confluence_score` | number | The 1h confluence vote share, 0–1 (see [/pulse](/api/pulse)) |
| `results[].oi_trend` | string | From the 4h open-interest change: `RISING` (> +3%), `FALLING` (< −3%), `FLAT`, or `UNKNOWN` without history |
| `results[].cex_dex_spread_bps` | number \| null | Coinbase vs DEX/Chainlink divergence in basis points, where the CEX-DEX feed covers the token; else null |
| `results[].cex_dex_direction` | string \| null | `cex_premium` or `dex_premium`, or null |
| `meta` | object | Common metadata ([Response Schemas](/reference/response-schemas#meta)) |
| `meta.offering` | string | `pulse_screener` |
| `meta.cex_dex_data_age_seconds` | number | Age of the CEX-DEX snapshot the divergence columns come from |
| `meta.cex_dex_tokens_available` | number | Tokens that snapshot covers |
| `meta.cached` | boolean | Optional. `true` when the rows come from the 60-second cache |
| `meta.cache_age_seconds` | number | Optional. With `cached`: how old the cached scan is |

`meta.as_of` holds `market_data`, `candles_1h` and `candles_4h` (the oldest of the markets' newest closed
candles), `oi_history` and `cex_dex`.

## Errors

| Status | Reason |
|--------|--------|
| 400 | `top_n` outside 1–50 (before any price is quoted) |
| 402 | Payment required (the standard x402 flow) |
| 429 | Rate limit exceeded |
| 503 | Service disabled, payments down, or an upstream feed is missing or stale; no price is quoted |
| 504 | Engine timeout (not charged) |
